# Words and phrases banned from tier-1 questions (docs/redesign.md §2.2).
#
# A match anywhere in a tier-1 stem or option is a lint ERROR. Tiers 2 and 3
# are not checked against this list at all.
#
# This is not a ban on the ideas. "Should the big companies be owned by the
# government?" asks the same question as one using "nationalisation" and is in
# bounds. Where no plain phrasing exists, the question belongs at tier 2 — that
# is the list doing its job, not failing.
#
# Maintenance rule: a term goes on this list when a novice reviewer says they
# would have to look it up (docs/redesign.md §9). The list is expected to grow.
#
# Matching is whole-word and case-insensitive, so multi-word phrases work and
# "capitalist" does not match inside another word.
