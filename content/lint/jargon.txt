# Jargon — the movement's technical vocabulary.
#
# SPEC.md §11 principle 6: the stem must be answerable without knowing the
# ideology's vocabulary. Describe the idea in plain words and put the technical
# term in a tooltip.
#
# `npm run lint:content` enforces two things:
#   - a term from this list in a STEM is an error, always. The stem is what
#     everyone answers; it cannot assume the vocabulary.
#   - a term in an OPTION is an error unless the question's tooltip mentions it.
#     Options may use a camp's own words (principle 5 requires it), but the
#     reader has to be able to look them up.
#
# Questions marked `self_id: true` are exempt, since naming traditions is the
# whole point of those (principle 10).
#
# Matching is case-insensitive, on whole words. Editable: a term earns its place
# here if a respondent could plausibly answer the question wrongly through not
# knowing it, not merely because it sounds technical.
